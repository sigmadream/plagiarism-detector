## 연구 배경 및 목적

- 소프트웨어 개발 과정에서 프로그램 코드의 표절 탐지 및 코드 클론 분석의 필요성이 증가함
- 기존 표절 탐색 도구(MOSS, JPlag 등)의 한계를 보완하기 위해 생물정보학의 서열 정렬 기법을 프로그램 소스코드 분석에 응용
- 두 프로그램 사이의 유사도를 정량적으로 측정하고, 유사한 코드 블록을 정밀하게 탐색하는 프레임워크를 제안

## 핵심 방법론

### 1. 프로그램 서열 생성 (PST: Program Static Tracing)

- 소스코드를 구문 분석(Parsing)하여 토큰화
- 단순 텍스트 비교가 아닌, 실행 흐름을 반영한 토큰 서열을 정적으로 추출
- 함수 호출, 제어문(if/for/while 등) 등 핵심 키워드를 추출하여 '프로그램 DNA' 생성
- 소스코드를 선형적인 서열로 변환하여 분석 효율을 향상

### 2. 적응적 지역 정렬 (LAA: Adaptive Local Alignment)

- 생물정보학의 Smith-Waterman 알고리즘 및 Gotoh 알고리즘을 프로그램 코드 분석에 맞게 확장
- 고정된 유사도 행렬 대신 키워드 출현 빈도에 기반한 적응적 행렬 사용
  - 흔한 코드 패턴(예: `int`, `return`)보다 희귀한 코드 패턴(특정 함수 호출 등)의 일치를 더 중요하게 평가
- 코드 내 각 토큰의 중요도에 따라 서로 다른 점수(Scoring)와 갭 패널티(Gap Penalty) 부여
- 단순 일치를 넘어 구조적 유사성을 포착

### 3. 확률 모델 기반 표절 판정

- 극단치 분포(Extreme Value Distribution) 확률 모델 도입
- 두 프로그램의 유사도가 우연히 발생할 확률을 계산
- 객관적인 표절 판정 임계치(Threshold) 설정
- 단순 유사도 점수가 아닌 통계적 유의성에 기반한 판정

### 4. 프로그램 진화 분석

- 유사도 분석 결과를 계통수(Phylogenetic Tree) 형태로 시각화
- 여러 프로그램이 어떻게 수정·발전해왔는지 추적
- 프로그램 간의 클러스터링을 통한 그룹 관계 분석

## 기존 연구와의 비교

### 기존 도구의 한계

| 도구 | 기법 | 한계점 |
|------|------|--------|
| MOSS | Winnowing | 토큰 수준의 단순 비교, 구조적 변형에 취약 |
| JPlag | GST(Greedy String Tiling) | 고정된 매칭 기준, 부분 변형 탐지 한계 |
| 기타 | 메트릭/트리 기반 | 확장성 부족, 계산 비용 높음 |

### 제안 기법의 장점

- 코드의 부분적 수정이나 순서 변경에도 유사 구간을 효과적으로 탐지
- 적응적 가중치를 통해 코드의 맥락적 중요도를 반영
- 확률 모델을 통한 객관적 판정 기준 제시
- 계통수 분석으로 코드 진화 관계를 정성적으로 파악 가능

## 실험 결과

- JPlag(GST 알고리즘 기반) 등 기존 대표 시스템과 비교 실험 수행
- 제안한 적응적 알고리즘(LAA)이 고정 행렬 방식이나 GST 알고리즘 대비:
  - 더 높은 민감도(Sensitivity) 달성
  - 더 높은 정확도(Accuracy) 달성
- 특히 부분적 코드 수정, 코드 순서 변경, 변수명 변경 등의 변형에 대해서도 우수한 탐지 성능 입증

## 결론 및 기여

1. 단순 유사도 점수 산출을 넘어 확률 모델 기반 객관적 판정 기준 제시
2. 계통수를 이용한 진화 분석 도구 통합
3. 생물정보학의 서열 정렬 기법을 프로그램 분석에 창의적으로 응용
4. 활용 분야:
   - 교육 현장의 프로그래밍 과제 표절 검사
   - 소프트웨어 저작권 관리
   - 소프트웨어 유지보수 및 코드 클론 분석
